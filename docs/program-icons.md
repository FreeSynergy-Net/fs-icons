# Programme icons, set `freesynergy` (fs-packages, fs-tasks, fs-people, fs-calendars, fs-files, fs-texts, fs-maps and 12 more)

Status: draft for review, not in the catalogue. Set id `freesynergy`, name "FreeSynergy". Files: `FreeSynergy-apps/apps/<id>.svg` (colour) and `<id>-symbolic.svg`. Entries: `FreeSynergy-apps/icons.toml`. Second selectable set: `freesynergy-playful` ("FreeSynergy Playful", `docs/program-icons-playful.md`).

Origin / Ursprung: this set is a mix. Form and motifs come from the former serious draft (set id `freesynergy-serious`, now consumed into this set and no longer a set of its own); colours and the highlight come from the playful set. / Dieses Set ist eine Mischung: Form und Motive vom früheren ernsteren Entwurf (Set-ID `freesynergy-serious`, in dieses Set aufgegangen, kein eigenes Set mehr), Farben und Aufheller vom verspielten Set.

Family rules / Familienregeln: 128x128 viewBox, tile 112 px with radius 10 (about 9 %), one vivid colour family per programme (diagonal gradient, light top-left to dark bottom-right, same colours as the playful set), one soft white highlight fading out from the top-left corner (opacity 0.34 to 0, no hard edge), no shadow, no filters, no text. Glyphs are flat, white with a tinted second tone and fine detail (small radii 1.5 to 3). Symbolic: 16x16 grid, `currentColor`, small radii, shapes of the serious draft, for bars and small sizes; they are single-coloured, so the colours do not change them. Licence for all files: `MIT` (`LICENSE-MIT`), own drawing, origin FreeSynergy project; nothing traced from another set.

## Frontend badge

A frontend variant of a programme icon (`<id>-frontend.svg`) carries a small dark circle with a white window glyph and a white ring in one corner (about 30 % of the tile). The corner is set per icon with `badge_corner` in `icons.toml`: `br` (bottom right) is the default, exceptions are `tr` and `bl`, chosen so the badge does not cover the main motif. If the white ring has less than 3:1 contrast against the tile colour under the badge, a thin dark outer ring (#0F172A, 1.25 px) is added automatically. Symbolic icons get no badge.

## Frontend-Abzeichen

Die Frontend-Fassung eines Programm-Icons (`<id>-frontend.svg`) trägt in einer Ecke einen kleinen dunklen Kreis mit weißem Fensterzeichen und weißem Ring (etwa 30 % der Kachel). Die Ecke steht je Icon als `badge_corner` in `icons.toml`: `br` (unten rechts) ist Standard, Ausnahmen sind `tr` und `bl`, so gewählt, dass das Abzeichen das Hauptmotiv nicht verdeckt. Liegt der Kontrast des weißen Rings zur Kachelfarbe unter dem Abzeichen unter 3:1, kommt automatisch ein dünner dunkler Außenring (#0F172A, 1,25 px) dazu. Symbolic-Icons bekommen kein Abzeichen.
